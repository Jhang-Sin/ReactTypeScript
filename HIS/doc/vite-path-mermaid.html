建議寫法（相對路徑）

<a href="HIS/doc/structure-diagram.html" target="_blank">開啟說明</a>

✔ 相對於網站根目錄（public）即可正常運作，不會產生多餘的子路徑。

React / Vite 動態 base（進階）

{`<a href={\`${import.meta.env.BASE_URL}HIS/doc/structure-diagram.html\`}>開啟</a>`}

✔ 在不同 base 設定（例如部署在子路徑）時，Vite 會自動補上正確前綴。

錯誤示範（不要這樣寫）

<a href="/public/HIS/doc/structure-diagram.html">錯誤連結</a>

✖ 不要在 href 中寫 /public/，public 是專案內部目錄，網址不包含該層。

小結：
  • Vite 與 GitHub Pages 將 public/ 視為網站根目錄（root）。
  • 放在 public/HIS/doc/structure-diagram.html 的檔案，實際可透過 /HIS/doc/structure-diagram.html 存取。
  • 若需要處理不同部署 base，建議使用 import.meta.env.BASE_URL（Vite）或相對路徑。
