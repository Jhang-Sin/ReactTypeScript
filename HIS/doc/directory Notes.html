資料夾 / 檔案位置用途說明
public/data/整個 HIS 共用的 JSON 資料（醫師、病患、時段、排班…）
public/HIS/common/css/所有模組都可共用的 CSS
public/HIS/common/js/utilities.js全域通用工具函式（字串、時間、格式化…）
public/HIS/common/js/modal.js統一使用的彈出視窗模組
public/HIS/common/js/condition-config.js掛號規則設定（可擴充角色 / 條件）
public/HIS/common/js/condition-engine.js掛號規則引擎（依角色 + 時段自動套用）
public/HIS/common/data/共用同義碼（noonType、noonTime、depCode）
public/HIS/Register/index.html掛號系統首頁（含 Router + 左側功能列）
public/HIS/Register/style.css掛號系統專用 CSS
public/HIS/Register/js/router.js巢狀頁面路由載入器（處理 reg_form / reg_list / reg_info）
public/HIS/Register/js/reg_form.js掛號作業邏輯（查詢 / 掛號）
public/HIS/Register/js/reg_list.js掛號紀錄列表邏輯
public/HIS/Register/js/reg_info.js掛號詳細資料邏輯
public/HIS/Register/pages/reg_form.html掛號作業頁面（查詢病歷 + 顯示可掛號醫師）
public/HIS/Register/pages/reg_list.html掛號紀錄頁面
public/HIS/Register/pages/reg_info.html掛號詳細資料頁面
public/HIS/login/login.html登入系統頁面
