Router 與事件載入教學

🔄 Router.js 動態載入機制

HIS 系統的多模組設計（如掛號、病歷、醫囑）會透過 router.js 控制頁面切換， 點擊左側選單時，系統以 AJAX（fetch()）方式載入對應頁面，而非整個網頁重新整理。

流程如下：

  1. 使用者點擊左側功能（含 data-page 屬性）
  2. router.js 讀取該屬性 → 使用 fetch() 取得對應 HTML 頁面
  3. 將頁面內容插入 #content 區域
  4. 自動尋找頁面中的 <script> 標籤並重新執行
  5. 於 console 顯示載入成功 / 錯誤訊息
// router.js 範例
document.addEventListener("DOMContentLoaded", () => {
  const links = document.querySelectorAll("[data-page]");
  const content = document.getElementById("content");

  links.forEach(link => {
    link.addEventListener("click", e => {
      e.preventDefault();
      const page = link.getAttribute("data-page");
      loadPage(`pages/${page}`);
    });
  });

  async function loadPage(page) {
    try {
      console.log(`[router.js] 載入頁面: ${page}`);
      content.innerHTML = "載入中...";
      const res = await fetch(page);
      const html = await res.text();
      content.innerHTML = html;

      // 重新執行該頁面的 script
      const scripts = content.querySelectorAll("script[src]");
      scripts.forEach(oldScript => {
        const newScript = document.createElement("script");
        newScript.src = oldScript.src;
        newScript.onload = () => console.log(`[router.js] Script loaded: ${oldScript.src}`);
        newScript.onerror = () => console.error(`[router.js] Script load failed: ${oldScript.src}`);
        document.body.appendChild(newScript);
      });
    } catch (err) {
      console.error(`[router.js] 載入失敗: ${err.message}`);
    }
  }
});

👉 優點：頁面切換快、不需整頁重整。
⚠️ 缺點：動態載入後，部分事件可能未綁定（如下段說明）。

❗ 事件未觸發問題：查詢按鈕無反應

問題現象：searchBtn 點擊後沒有反應，console.log() 也未觸發。

🔍 問題原因

  • 掛號頁面是由 router.js 動態載入，並非整個文件重新載入。
  • DOMContentLoaded 僅在整個文件首次載入時觸發一次。
  • 因此在 reg_form.js 中使用 document.addEventListener("DOMContentLoaded") 時，不會再次執行。

🚫 錯誤寫法

document.addEventListener("DOMContentLoaded", () => {
  const searchBtn = document.getElementById("searchBtn");
  searchBtn.addEventListener("click", () => console.log("Clicked"));
});

✅ 正確修正

改為在頁面載入後立即執行初始化函式：

function initRegForm() {
  const searchBtn = document.getElementById("searchBtn");
  if (!searchBtn) {
    console.warn("[reg_form.js] 找不到搜尋按鈕 (#searchBtn)");
    return;
  }

  searchBtn.addEventListener("click", () => {
    console.log("[reg_form.js] 查詢按鈕被點擊");
    const mrNo = document.getElementById("mrNo").value.trim();
    if (!mrNo) {
      alert("請輸入病歷號！");
      return;
    }
    loadPatient(mrNo, true);
  });
}

// ✅ 立即執行初始化
initRegForm();

或於 router.js 中載入腳本後自動呼叫：

newScript.onload = () => {
  console.log(`[router.js] Script loaded: ${oldScript.src}`);
  if (typeof initRegForm === "function") initRegForm();
};

🧭 開發建議

  • 動態載入頁面時避免依賴 DOMContentLoaded。
  • 每個功能頁（如掛號、查詢、紀錄）應有獨立初始化函式。
  • 統一在 router.js 載入腳本後自動呼叫初始化。
  • 善用 console.log() 追蹤載入流程，方便除錯。
  • 保持 HTML 結構乾淨，互動邏輯放在 JS 檔中集中管理。
