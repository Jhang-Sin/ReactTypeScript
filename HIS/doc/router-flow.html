Router.js 運作流程

使用者點擊選單按鈕
(click on menu item)
讀取 data-page 屬性
(get data-page)
顯示「載入中」提示
(show loading placeholder)
fetch() 載入 HTML 子頁面
(fetch html)
失敗 → 顯示錯誤訊息
(show error)
✔
成功 → 將 HTML 插入 main#content
(innerHTML)
搜尋插入內容中的 <script src="..."> 標籤
(querySelectorAll('script[src]'))
逐一建立 <script> 元素並把 src 附加到 document.body
(createElement('script'), appendChild)
執行子頁面邏輯（事件綁定 & 初始化）
(reg_form.js / reg_list.js / reg_info.js 等)
Console Log
顯示載入動作與錯誤
使用者可操作
已完成載入並綁定事件
