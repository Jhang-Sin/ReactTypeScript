🧩 router.js 動態載入與 Script 重新執行流程

① DOMContentLoaded → 啟動 router.js

網頁載入完成後執行 router.js，註冊所有帶有 data-page 的選單連結事件。

② 使用者點擊功能連結

觸發 click 事件，讀取對應的 data-page 屬性（例如：reg_form.html）。

③ router.js 呼叫 loadPage()

開始以 fetch() 非同步載入 pages/ 資料夾下的對應頁面。

中間框架（#content）暫時顯示「正在載入頁面...」。

④ 載入成功 → 插入 HTML

以 innerHTML 將頁面內容插入至 #content 區域中。

⑤ 重新載入該頁 <script>

偵測新載入頁面中的所有 <script src="...">。

為每個 script 建立新節點並附加至 document.body。

自動修正路徑，如相對路徑會轉換為 js/對應檔名。

⑥ console 輸出狀態

載入成功 → 顯示 [router.js] ✅ Script loaded successfully

載入失敗 → 顯示 [router.js] ❌ Script load failed

這些訊息可在 F12 Console 觀察。

⑦ 頁面可操作

所有 JS 執行完成後，頁面互動功能（例如查詢、掛號等）即進入可使用狀態。
