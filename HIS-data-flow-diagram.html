🔹 開發原則：
- View 僅負責顯示與基本輸入檢查。
- Model 專注於邏輯（掛號、查詢、檢核）。
- Service 層統一管理 API 存取，避免重複程式碼。
- 模擬資料 (JSON / txt) 可作為暫時後端，日後可無痛切換至真實 API。

🔹 延伸： 新增功能（如病歷查詢、排班管理）可建立對應 Model & Service，並於 View 呼叫即可。
