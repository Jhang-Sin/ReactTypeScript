安全開新頁面教學：rel="noopener noreferrer" 與 window.open()

當我們在網頁中使用 target="_blank" 或 JavaScript 的 window.open() 開啟新頁面時，若不額外設定安全屬性， 可能導致被惡意網站「反向導向」（Tabnabbing 攻擊）。以下是安全的開新頁方式說明。

一、HTML 與 JS 開新頁安全性對照表

類型 用法範例 是否安全 備註
HTML 連結（無防護） <a href="https://example.com" target="_blank"> ❌ 不安全 新頁可透過 window.opener 反向控制原頁
HTML 連結（安全） <a href="https://example.com" target="_blank" rel="noopener"> ✅ 安全 阻止 opener 被建立
HTML 連結（最安全） <a href="https://example.com" target="_blank" rel="noopener noreferrer"> ✅ 安全 阻止 opener 並不傳送 Referer
JS 開新頁（預設） window.open('https://example.com') ❌ 不安全 新頁可操作原頁
JS 開新頁（安全） window.open('https://example.com', '_blank', 'noopener') ✅ 安全 與 rel="noopener" 等效
JS 開新頁（最安全） window.open('https://example.com', '_blank', 'noopener,noreferrer') ✅ 安全 完全阻止 opener，並不傳遞 Referer

二、HTML 範例

<!-- 不建議使用，容易被反向導向 -->
<a href="https://example.com" target="_blank">開啟外部網站 (不安全)</a>

<!-- 建議使用，加入 rel="noopener noreferrer" -->
<a href="https://example.com" target="_blank" rel="noopener noreferrer">
  開啟外部網站 (安全)
</a>

三、JavaScript 範例

// ❌ 不建議：容易被反向導向
window.open('https://example.com');

// ✅ 建議用法：加入 "noopener"
window.open('https://example.com', '_blank', 'noopener');

// ✅ 最安全：同時加入 "noreferrer"
window.open('https://example.com', '_blank', 'noopener,noreferrer');

// ✅ 進階安全作法：手動清除 opener
const newWin = window.open('https://example.com', '_blank');
if (newWin) newWin.opener = null;

四、補充說明

  • noopener：阻止新頁面取得 window.opener。
  • noreferrer：阻止瀏覽器傳送來源頁網址（Referer）。
  • window.opener = null;：在新頁面開啟後手動清除連結。

📘 建議：所有外部連結都應使用 rel="noopener noreferrer" 或在 JS 中加上 noopener 屬性。
