嵌入外部 HTML 的三種方式比較

方式 程式語法 顯示效果 特性說明
① <iframe> 
<iframe src="ModuleOperation.html"></iframe>
 ✅ 可執行內部 JS、CSS。
✅ 最獨立、安全。
⚠️ 跨網域需允許。
🚀 推薦用於正式嵌入。
② <object> 
<object type="text/html" data="ModuleOperation.html"></object>
 ⚙️ 可載入 HTML。
🚫 JS 有時不執行。
📜 比較舊的技術。
③ <div> + fetch() 
<div id="embedContainer"></div>
<script>
fetch("ModuleOperation.html")
  .then(r => r.text())
  .then(html => {
    document.getElementById("embedContainer").innerHTML = html;
  });
</script>
載入中...
 ✅ 直接顯示 HTML 內容。
🚫 JS 不會執行。
🚫 外部 CSS 不會生效。
⚙️ 可用於同域靜態內容展示。
